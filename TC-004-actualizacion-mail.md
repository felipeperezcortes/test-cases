# TC-004 - Validación de actualización de correo electrónico en datos personales.

## Objetivo:
Validar que el sistema permita al usuario actualizar su corre electrónico y muestre
una confirmación después de guardar el nuevo dato.

## Precondiciones
- El usuario debe estar logueado en el portal.
- El usuario debe estar en la sección de datos personales.
- El usuario cuenta con un correo electrónico previamente registrado.
- Existe una sección o menú donde se pueden editar los datos personales.

## Pasos:
1. Dentro de la sección de datos personales, hacer clic en el botón "Editar datos".
2. Localizar el campo "Correo electrónico".
3. Borrar el correo actual e ingresar un nuevo correo válido.
4. Reingresar el nuevo correo en el campo de confirmación (si aplica).
5. Hacer clic en el botón "Guardar" o "Actualizar".
6. Observar el mensaje que muestra el sistema después de intentar guardar los cambios.

## Resultado esperado:
El sistema debe mostrar un mensaje indicando que el correo electrónico fue actualizado correctamente.
