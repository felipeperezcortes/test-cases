## TC-004 – Validación de actualización de correo electrónico en datos personales

# Objetivo:
Validar que el sistema permita al usuario actualizar su correo electrónico en la sección de datos personales, mostrando un mensaje de confirmación y persistiendo el cambio correctamente.

# Precondiciones:
	•	El usuario está autenticado en el portal.
	•	El usuario se encuentra en la sección Datos personales.
	•	El usuario tiene un correo electrónico previamente registrado.
	•	La opción de edición de datos personales está disponible.

# Datos de prueba:
	•	Correo actual: correo.actual@ejemplo.com
	•	Nuevo correo válido: correo.nuevo@ejemplo.com

# Pasos:
	1.	En la sección Datos personales, hacer clic en “Editar datos”.
	2.	Ubicar el campo “Correo electrónico”.
	3.	Reemplazar el correo actual por el nuevo correo válido definido en los datos de prueba.
	4.	Reingresar el nuevo correo en el campo de confirmación (si aplica).
	5.	Hacer clic en “Guardar” o “Actualizar”.
	6.	Observar el mensaje mostrado por el sistema tras guardar los cambios.
	7.	Verificar que el correo actualizado se muestre correctamente en la sección de datos personales (o tras recargar la página / volver a ingresar a la sección).

# Resultado esperado:
	•	El sistema debe mostrar un mensaje indicando que el correo fue actualizado correctamente.
	•	El correo electrónico debe quedar actualizado y persistido, mostrando el nuevo valor en datos personales.

# Resultado real:
	•	No ejecutado.
