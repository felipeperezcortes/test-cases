# TC-003 – Validación de mensaje de error por saldo insuficiente en transferencia

## Objetivo:
Validar que el sistema impida una transferencia cuando el usuario ingresa un monto mayor al saldo disponible en la cuenta de origen, mostrando un mensaje de error por saldo insuficiente.

## Precondiciones:
	•	El usuario ha iniciado sesión en https://bancoficticio.demo
	•	El usuario se encuentra en la sección principal donde puede ver cuentas y saldos
	•	Existe una cuenta de destino válida para recibir la transferencia
	•	La cuenta de origen tiene saldo disponible menor al monto a transferir

## Datos de prueba:
	•	Cuenta de origen: saldo disponible $10.000
	•	Monto a transferir: $15.000 (mayor al saldo disponible)
	•	Cuenta de destino: cuenta válida registrada en el sistema

## Pasos:
	1.	Desde la página principal, hacer clic en “Transferencias”.
	2.	Seleccionar la cuenta de origen.
	3.	Ingresar el monto definido en los datos de prueba.
	4.	Seleccionar la cuenta de destino.
	5.	Hacer clic en “Transferir” o “Continuar”.
	6.	Observar el resultado de la operación y el mensaje mostrado por el sistema.

## Resultado esperado:
	•	El sistema debe impedir la transferencia.
	•	Se debe mostrar un mensaje de error indicando que el usuario no cuenta con saldo suficiente para realizar la operación.

## Resultado real:
	•	No ejecutado.
