# TC-002 – Validación de RUT vacío en login

## Objetivo:
Validar que el sistema impida el inicio de sesión cuando el usuario no ingresa su RUT en el formulario de login, mostrando un mensaje de error que indique la obligatoriedad del campo.

## Precondiciones:
	•	El usuario se encuentra en la página https://bancoficticio.demo/login
	•	Navegador compatible abierto (Chrome o Safari)

## Datos de prueba:
	•	Campo RUT: vacío
	•	Contraseña: valor genérico válido

## Pasos:
	1.	Ubicar el campo “RUT o usuario” en la pantalla de login.
	2.	Dejar el campo “RUT o usuario” vacío.
	3.	Ingresar una contraseña válida en el campo “Contraseña”.
	4.	Hacer clic en el botón “Ingresar”.
	5.	Observar el mensaje mostrado en pantalla.

## Resultado esperado:
	•	El sistema debe impedir el inicio de sesión.
	•	Se debe mostrar un mensaje de error indicando que el campo RUT es obligatorio.
	•	El mensaje debe guiar al usuario sobre el formato correcto esperado.

## Resultado real:
	•	No ejecutado.
