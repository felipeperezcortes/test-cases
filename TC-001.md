# TC-001 – Validación de formato de RUT en login

## Objetivo:
Validar que el sistema rechace el ingreso de un RUT con formato inválido durante el proceso de login, mostrando un mensaje de error claro que indique el formato correcto esperado.

## Precondiciones:
	•	El usuario se encuentra en la página https://bancoficticio.demo/login
	•	Navegador compatible abierto (Chrome o Safari)

## Datos de prueba:
	•	RUT inválido: 12345678
	•	Contraseña: valor genérico válido

## Pasos:
	1.	Ubicar el campo “RUT o usuario” en la pantalla de login.
	2.	Ingresar el RUT inválido definido en los datos de prueba.
	3.	Ingresar una contraseña válida en el campo “Contraseña”.
	4.	Hacer clic en el botón “Ingresar”.
	5.	Observar el mensaje mostrado en pantalla.

## Resultado esperado:
	•	El sistema debe impedir el inicio de sesión.
	•	Se debe mostrar un mensaje de error indicando que el formato del RUT no es válido.
	•	El mensaje debe incluir un ejemplo del formato correcto esperado.

## Resultado real:
	•	No ejecutado.
